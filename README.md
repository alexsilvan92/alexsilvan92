## 🚀 Proyecto destacado

### 🎮 [Playback — Retro Marketplace](https://sample-service-name-89mg.onrender.com/)

Marketplace full-stack de productos retro construido en equipo de tres. El proyecto más completo que he desarrollado hasta la fecha.

- **3 roles de usuario**: cliente, vendedor y administrador
- **Pagos reales** con Stripe + transferencias automáticas a vendedores
- **Autenticación** JWT + OAuth 2.0
- **Gestión de imágenes** con Cloudinary
- **Internacionalización** ES/EN y modo oscuro/claro
- Sistema de incidencias, emails transaccionales y asistente de búsqueda con IA
- Desplegado en **Render**

`React` `Flask` `Python` `PostgreSQL` `JWT` `Stripe` `Cloudinary` `Docker` `Tailwind`
